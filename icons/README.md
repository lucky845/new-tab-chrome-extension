# 图标文件说明

此文件夹用于存放插件的图标文件。

## 需要的图标文件

根据 `manifest.json` 配置，需要以下图标文件：

- `icon16.png` - 16x16 像素图标
- `icon48.png` - 48x48 像素图标
- `icon128.png` - 128x128 像素图标

## 图标要求

- 格式：PNG
- 背景：透明或白色
- 风格：简洁现代，与插件功能相关

## 临时解决方案

如果暂时没有图标文件，可以：

1. 使用在线图标生成器创建简单的图标
2. 从图标库（如 Material Icons、Feather Icons）下载合适的图标
3. 使用设计工具（如 Figma、Sketch）创建自定义图标

## 推荐图标主题

考虑到这是一个智能新标签页插件，建议使用：

- 天气相关的图标（如太阳、云朵）
- 仪表板或主页图标
- 现代化的几何图形

---

**注意**: 图标文件是插件发布到 Chrome Web Store 的必需文件。
