# Contributing to Infinity-Next Tab

First off, thank you for considering contributing to Infinity-Next Tab! It's people like you that make this such a great tool.

We welcome any form of contribution, from reporting a bug to submitting a feature request, or even writing code to help us improve the extension.

## How Can I Contribute?

### Reporting Bugs

- **Ensure the bug was not already reported** by searching on GitHub under [Issues](https://github.com/your-username/your-repo-name/issues).
- If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/your-username/your-repo-name/issues/new). Be sure to include a **title and clear description**, as much relevant information as possible, and a **code sample or an executable test case** demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

- Read through the documentation carefully and make sure your suggestion is not already covered.
- If you have an idea for an enhancement, please [open a new issue](https://github.com/your-username/your-repo-name/issues/new) to discuss it. This allows us to coordinate our efforts and prevent duplication of work.

### Pull Requests

The process for submitting a pull request is as follows:

1.  **Fork the repository** and create your branch from `master`.
2.  **Make your changes**. Please follow the existing code style.
3.  **Ensure your code lints**. We haven't set up a linter yet, but try to maintain a clean and readable code style.
4.  **Issue that pull request!** Once you've submitted your pull request, we'll review it as soon as possible.

## Styleguides

- **JavaScript**: We follow the standard modern JavaScript (ES6+) style. Use meaningful variable names and add comments where necessary to explain complex logic.
- **CSS**: We use plain CSS. Please try to keep the CSS organized and follow the existing structure.
- **Commit Messages**: Please write clear and concise commit messages.

## Code of Conduct

This project and everyone participating in it is governed by the [Code of Conduct](./CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior.

Thank you for your contribution!
